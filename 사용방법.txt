원클라우드 현황판 사용 방법
==========================

[실행]
1. "원클라우드 현황판 실행.bat" 을 더블클릭합니다.
   - 처음 실행하면 바탕화면과 이 폴더에 "원클라우드 현황판" 바로가기(원클라우드 아이콘)가 생깁니다.
     다음부터는 바로가기로 실행하면 됩니다.
2. Edge 앱 창으로 현황판이 열립니다. (Edge가 없으면 Chrome, 둘 다 없으면 기본 브라우저)

[자동 갱신]
- D:\12.ONECLOUD\원클라우드 계약서관리.xlsx 를 몇 초마다 확인합니다.
- 엑셀에서 내용을 고치고 "저장"하면 몇 초 안에 지도·매출·목록이 다시 계산됩니다.
- 엑셀을 열어 둔 상태에서도 읽을 수 있습니다. (저장해야 반영됩니다)
- "원본 엑셀 열기" 버튼으로 엑셀 파일을 바로 열 수 있습니다.

[입금 현황 탭]
- 위쪽 "입금 현황" 탭에서 D:\12.ONECLOUD\8. 입금내역\입금내역정리.xlsx 를 보여 줍니다. 저장하면 자동 갱신됩니다.
- 업체마다 3줄(월금액 / 입금액 / 입금일) 형식 그대로 읽습니다. 월 머리글(12월, 1월 …)이 늘어나도 그대로 따라갑니다.
- 칸 색: 파랑 = 입금, 노랑 = 늦은 입금(청구월 다음달 말을 넘김), 주황 = 일부 입금, 빨강 = 미납, 점선 = 기준월 이후
- 미수 기준월 기본값은 "월말이 지난 마지막 달"입니다. 엑셀 합계(미납액)와 맞춰 보려면 마지막 달을 고르세요.
- 업체 이름을 누르면 월별 청구·입금·입금일 상세가 열립니다.

[엑셀 작성 규칙 (지금 쓰시는 방식 그대로)]
- "사용" 시트: 코드가 있는 행 = 업체
- 법인명 칸 색: 회색 = 해지 / 주황(FFC000) = 미사용 / 그 밖의 색 = 클라우드 전환 완료
- "종료" 시트의 업체는 해지 수에 더해집니다.
- 매출 = 월금액 x 올해 사용한 달 수 (사용시작일이 비었거나 글자면 작년 이전부터 사용으로 봄,
  시작일이 기준월 이후면 "도입 예정")
- 시트 아래쪽 "영업 진행" / "영업 종료" 영역은 영업 파이프라인 칸에 나옵니다.

[설정 바꾸기 - config.json]
- excel  : 사용 현황 엑셀 경로
- payment: 입금내역정리 엑셀 경로
- (참고) 위 두 항목 모두 (이 폴더 기준 상대 경로 또는 D:\... 전체 경로, 역슬래시는 \\ 두 번)
- port   : 내부 주소 번호 (다른 프로그램과 겹치면 8766 등으로 변경)
- browser: "edge-app" = 프로그램 창 / 그 밖의 값 = 기본 브라우저 탭

[참고]
- 프로그램은 내 PC 안(localhost)에서만 동작하며 외부로 데이터를 보내지 않습니다.
- 처음 한 번 남한 지도 모양을 인터넷에서 받아 lib 폴더에 보관합니다. 인터넷이 안 되면 칸 모양 지도로 표시됩니다.
- 창을 닫으면 1분 정도 뒤 백그라운드 프로그램도 스스로 종료됩니다.
- 문제가 생기면 이 폴더의 server.log 를 확인하세요.
